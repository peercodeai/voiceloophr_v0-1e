# VoiceLoop HR Documentation

This directory contains all project documentation organized by category.

## 📁 **Directory Structure**

### 📚 **Guides** (`/guides`)
Setup guides, configuration instructions, and deployment documentation.

- **AWS Setup**: Environment configuration and permissions
- **Supabase Setup**: Database configuration and migration guides
- **Calendar Integration**: Google Calendar and Microsoft Graph setup
- **Production Deployment**: Vercel deployment and environment setup
- **Security**: Security best practices and configuration
- **Project Overview**: High-level project architecture and features

### 🔧 **Development** (`/development`)
Development instructions, issue tracking, and code quality guidelines.

- **Critical Issues**: Security vulnerabilities and critical bugs
- **High Priority Issues**: Performance and architecture improvements
- **Medium Priority Issues**: TypeScript, testing, and documentation
- **Pre-Push Checklist**: Code quality and deployment checklist

### 📊 **Analysis** (`/analysis`)
Project analysis, research documents, and strategic recommendations.

- **PM Reports**: Product management analysis and recommendations
- **Strategic Recommendations**: Business strategy and feature planning
- **Comparison Analysis**: Competitive analysis and market research

### 🗄️ **Archive** (`/archive`)
Legacy documentation and outdated guides.

- **Old Upgrade Instructions**: Previous version upgrade guides
- **Deprecated Features**: Outdated feature documentation

## 🚀 **Quick Start**

1. **New to the project?** Start with `guides/PROJECT_OVERVIEW.md`
2. **Setting up development?** Check `guides/SETUP_GUIDE.md`
3. **Deploying to production?** Follow `guides/PRODUCTION_DEPLOYMENT.md`
4. **Need to fix issues?** Review `development/` directory

## 📋 **Documentation Standards**

- All markdown files use consistent formatting
- Code blocks include language specification
- Links are relative to the project root
- Images are stored in `public/images/docs/`
- API documentation is in `docs/openapi.yaml`

## 🔄 **Keeping Documentation Updated**

- Update guides when configuration changes
- Add new issues to development directory
- Archive outdated documentation
- Update README when adding new categories
